Real payroll logic, not a CRUD demo.

Built for a short-term rental property management business. Replaces manual spreadsheets with a secure, real-time, multi-user platform for payroll, billing, and operational data, with zero server maintenance.

Vanilla JavaScript, no framework. Live in production on GitHub Pages with a cloud database, so changes from one user appear instantly for the other, no refresh needed.

Two users, tightly scoped permissions:
Admin (Jeinna) : full access, all 6 tabs Limited (Greg) : locked to Payroll tab only

Greg can log entries but can't touch Summary, Database, or Billing. Every action he takes is logged and visible to the admin.

~90% fewer database reads than polling.

Built on Supabase Realtime WebSocket subscriptions instead of polling. Only the affected table re-fetches on each change, cutting egress significantly.

Single-File SPA
No build tools or frameworks. Ships as one HTML file with vanilla JS and CSS custom properties.
Realtime WebSocket
Push-based change notifications on every subscribed table, with no polling. Reconnects automatically with backoff; falls back to 10-second polling if WebSocket is unavailable.
Session-Based Auth
Role-aware authentication with a 1-hour inactivity timeout and sessionStorage persistence. Refreshing returns users to the exact tab they were on.
Paginated REST Fetches
HTTP Range headers bypass Supabase's 1,000-row API cap, supporting unlimited historical data with fingerprint-based deduplication.
GitHub Pages Deployment
Drag-and-drop deploy, zero DevOps overhead. Runs in production on free static hosting backed by a cloud database.
Egress Optimization
Targeted re-fetches on WebSocket events: idle means zero requests, a saved entry re-fetches only that table. About 90% fewer reads than the previous polling setup.
Scroll Position Preservation
Double-requestAnimationFrame restore prevents the scroll-jump issue common with innerHTML replacement.
Fresh-State Logout
Every field, filter, and cached state clears on sign-out, so the next session always starts blank.

Six sections, one platform.

Each tab is a complete workspace, with its own filters, inline editing rules, export options, and real-time data flow.

Dashboard
Four live stat cards (current month payroll, all-time payroll, active cleaner count, properties in database) plus a recent entries table and top earners panel. Entries touched by the limited user are highlighted for admin visibility.
Log Work Entry
Cleaner dropdown auto-populates from the database; property dropdown narrows to the selected cleaner; rate auto-fills. Three work types: Cleaning, Inspection, Misc/Bonus. Form state persists across tab switches.
Sorted Summary
Full payroll record with four live filters: date range, cleaner, property. Admin inline editing: date, rate override, additional rate, notes, delete. Greg's edits highlighted field-by-field. CSV export.
Employee Payroll Report
Per-cleaner pay-statement cards with an active staff sidebar. Inline editing with confirmation dialogs, manual pay rows for bonuses, and two-way sync with Summary. Print/PDF and CSV export.
Billing System
Client-facing invoices grouped by property brand. Misc line items per group with live-updating subtotals and a grand total card. CSV export includes billing and misc line items.
Database Editor
Employee rates, billing rates, and an add-new tab for rates, employees, and properties, admin only. Duplicate detection warns before creating a second copy.
Floating Chat
Private messaging between the two users from any tab, with an unread badge and persistent history in Supabase. Realtime-powered, no polling.
Activity Log
Admin-only log of every action the limited user takes: new entries, rate overrides, deletions, manual pay rows. Capped at 500 entries, with mark-all-read and clear options.
